# AGENTS.md

Permanent rules for coding agents working on qualitycheck.

The rules are those of a project generated by copierpythontemplate (private) with the default answers (no profile, no `overrides`): its `AGENTS.md` rules apply here, with the differences below, which win.

- Base files written by hand, not generated: there is no `.copier-answers.yml`, and `copier update` does not apply.
- Structure: `src/qualitycheck/` for code; `tests/{unit,integration,bdd}/` for test code only (scenarios in `tests/bdd/features/`); `test-cases/` for test data; `specs/` for Spec Kit; `docs/` for ADRs.
- Product: one command, `uv run qualitycheck`, run in the project it checks; it never checks itself through CI.
- Tests: run the tests the change touches; the full suite only when the user asks.
